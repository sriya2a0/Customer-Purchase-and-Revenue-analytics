# Customer Purchase & Revenue Analytics

## Project Overview

This project analyzes customer purchasing behavior, product performance, and sales/revenue trends using Python, Excel, and Power BI.

The objective is to transform raw customer purchase data into meaningful business insights through data cleaning, analysis, visualization, and an interactive Power BI dashboard.

---

## Business Problem

Businesses need to understand:

- Who their customers are
- Which products perform well
- How revenue varies across customer segments
- How discounts and subscriptions influence purchases
- Which locations contribute the most revenue

This project addresses these questions through data analysis and visualization.

---

## Project Objective

The main objectives of this project are to:

- Analyze customer purchasing behavior
- Identify product performance patterns
- Analyze revenue and purchase trends
- Compare customer segments
- Understand discount and subscription behavior
- Identify high-performing locations
- Present insights through an interactive dashboard

---

## Tech Stack

- **Python** – Data cleaning, preprocessing and analysis
- **Excel** – Data validation and exploratory analysis
- **Power BI** – Data visualization and dashboard development
- **DAX** – Measures and KPI calculations

- Age

- Category

- Size
- Color
- Season
- Review Rating
- Subscription Status
- Shipping Type
- Discount Applied
- Previous Purchases
- Payment Method
- Frequency of Purchases

---

## Project Workflow

**Raw Data → Python → Excel → Power BI → Business Insights**

### 1. Data Preparation
- Cleaned and prepared the dataset using Python
- Checked data quality and consistency
- Performed validation and exploratory analysis using Excel

### 2. Data Analysis
Analyzed customer, product and revenue-related patterns.

### 3. Dashboard Development
Created an interactive Power BI dashboard with KPIs, charts and slicers to enable business-focused analysis.

---

## Dashboard Highlights

The Power BI dashboard provides insights into:

- **Total Revenue**
- **Total Purchases**
- **Average Purchase Amount**
- **Average Review Rating**
- Revenue by Gender
- Customer Segmentation
- Discount Purchase Rate by Product
- Revenue Contribution by Age Group
- Top 5 Products by Rating
- Location-wise Revenue and Customers

### Interactive Filters

Users can analyze the dashboard using filters such as:

- Location
- Season
- Subscription Status
- Shipping Type
- Payment Method
- Discount Applied

## Key Business Insights

- Identified differences in revenue contribution across customer segments.
- Analyzed product ratings to identify highly rated products.
- Compared revenue performance across different age groups.
- Examined discount purchase patterns across products.
- Identified locations contributing significantly to revenue and customer volume.
